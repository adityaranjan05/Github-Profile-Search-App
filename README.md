# GitHub Profile Search App

A web application to search for GitHub users and view their profile information.

**Live Demo**: [https://github-profile-search-app-mu.vercel.app/](https://github-profile-search-app-mu.vercel.app/)

## Features

- Search GitHub users by username
- Display user profile information (name, bio, followers, following, public repos)
- Real-time loading state
- Error handling for invalid usernames
- Responsive design for mobile and desktop

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub REST API
